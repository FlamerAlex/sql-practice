## Overview

This repository contains SQL exercises created during QA database-testing practice. The queries demonstrate how data can be selected, filtered, aggregated, joined, and validated.

## Contents

| File | Topics |
| --- | --- |
| [`select-queries.sql`](select-queries.sql) | `SELECT`, `WHERE`, `LIKE`, `BETWEEN`, `DISTINCT`, `ORDER BY`, `LIMIT`, aggregate functions, `UNION`, `HAVING`, and `CASE` |
| [`join-queries.sql`](join-queries.sql) | `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, and a subquery |
